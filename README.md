## How it is made

`draw.py` (in the build directory) draws `entry.png` (1024×1024, 194,354 bytes, SHA-256 `d84c6cfa6b8768ca439215a1b2cb00a8bb22448ec1f9f9868e03ed31da2f593d`) with PIL. `main.py` is a stdlib-only copy program: it verifies the image's size and SHA-256, then copies it to `/output/entry.png`. Two runs produce byte-identical output.
